# הסרטון: איך נבנתה נחיתה רכה

סרטון הסבר של כ-6 דקות. נוי ורון (מהאתר של מדעי המוח) מנחים, וביט (מהאתר של מדעי המחשב) מתארח ומספר להם על האתר הראשון, שממנו הם נולדו. יחד הם מסבירים איך רועי בנה את האתר, וכל מושג מקבל הסבר פשוט וכרטיס "מילון קטן". הסרטון בנוי ב-[Remotion](https://www.remotion.dev): כל פריים מצויר מקוד React, ואז מקודד ל-MP4. הכלי לא חלק מהאתר; הבנייה של האתר לא נוגעת בתיקייה הזאת.

## סיור באתר (Tour)

סרטון אנכי קצר (9:16, כדקה) שבו נוי ורון עוברים עם סטודנט חדש על מה שיש באתר של מדעי המוח: החיפוש והלשוניות, קישורים וקבוצות וואטסאפ, מדריכים, המערכת והקורסים, לוח השנה, הצ'אט, וההוספה למסך הבית. התסריט ב-`TOUR_SCENES` שבסוף `src/script.ts`, הלוחות (`tour...`) בסוף `src/boards/index.tsx`, והקולות ב-`public/audio/lines/tour-*.mp3`. צילומי המסך (`public/shots/neuro-*.webp`) צולמו מבנייה מקומית של האתר (`FACULTY=neuro`).

```bash
npm run render:tour                     # out/nechita-raka-tour.mp4, 1080x1920
```

## איך זה בנוי

| קובץ | מה יש בו |
|---|---|
| `src/script.ts` | **התסריט**: הסצנות, מי על הבמה, מי אומר מה, התנוחה של הדמות, ומושגים להסבר. הסימן `^` בטקסט הוא רמז: כשהמילה שאחריו נאמרת, הלוח מתקדם צעד. |
| `src/boards/index.tsx` | הלוח המונפש של כל סצנה (הפאנל הלבן במרכז). |
| `src/Character.tsx` | הדמויות: כניסה, נשימה, תנוחה לכל שורה, ותנועת דיבור לפי עוצמת הקול. |
| `src/Board.tsx`, `src/Overlay.tsx`, `src/Intro.tsx`, `src/Background.tsx` | הפאנל וכרטיסי הפרקים, כתוביות, מילון, סרגל פרקים, פתיחה ורקע. |
| `src/timeline.ts` | מחשב מתי כל שורה מתחילה, לפי אורך הקול האמיתי (או הערכה כל עוד אין קול). |
| `src/sounds.ts`, `src/Sound.tsx` | עיצוב הסאונד: אפקטים, מוזיקת רקע שיורדת מתחת לדיבור. |
| `scripts/generate-audio.mts` | מייצר ב-ElevenLabs את הקולות, האפקטים והמוזיקה, וכותב את `src/audio-manifest.json`. |
| `public/` | תמונות הדמויות, צילומי מסך אמיתיים של שני האתרים, גופנים וקבצי הקול. |

## הפקה

מתוך `tools/explainer`:

```bash
npm install
ELEVENLABS_API_KEY=... npm run audio   # קולות, אפקטים ומוזיקה (פעם אחת; מה שכבר נוצר לא נוצר שוב)
npm run studio                         # תצוגה חיה בדפדפן, אפשר לגלול בזמן
npm run render                         # out/nechita-raka-explainer.mp4, 1080p
```

- **קולות:** בלי `VOICE_NOI`, `VOICE_RON` ו-`VOICE_BIT`, הסקריפט מעצב שלושה קולות חדשים לפי תיאור הדמויות (Voice Design), שומר אותם בחשבון, ומשאיר דוגמאות ב-`public/audio/voices/`. כדי להשתמש בקול אחר (למשל קול משובט), מעבירים את ה-Voice ID במשתנה.
- **עלות:** הקריינות כ-3,900 תווים במודל Eleven v3, ועוד 12 אפקטים וקטע מוזיקה של 4 דקות. המוזיקה דורשת חבילה בתשלום; אם היא נכשלת, הסרטון יוצא בלי מוזיקה ואפשר לנסות שוב עם `npm run audio -- --only=music`.
- **בלי קול:** אפשר לרנדר גם לפני `npm run audio`. אז התזמון משוער והדמויות "מדברות" בתנועה סינתטית. זה טוב לבדיקת ויזואל, לא לסרטון הסופי.
- **בסביבת הענן:** Chromium כבר מותקן, ומעבירים אותו כך: `REMOTION_CHROME=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell npm run render`.
- Remotion חינמי לשימוש אישי ולצוותים קטנים (ראו את הרישיון שלו).
- **מוזיקה:** ‏"Wallpaper" של Kevin MacLeod ‏(incompetech.com), ברישיון CC BY 4.0. הרישיון מחייב קרדיט, והקרדיט מופיע אוטומטית בסוף הסרטון כשיש קובץ `public/audio/music/bed.mp3`.
