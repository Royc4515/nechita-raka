# סטודיו הסבר: "איך בניתי את נחיתה רכה"

סרטון הסבר של כ-6 דקות: 12 שקופיות שמצוירות בדפדפן, קריינות בעברית מ-ElevenLabs, וייצוא לקובץ וידאו. הכלי לא חלק מהאתר; הבנייה של האתר לא נוגעת בתיקייה הזאת.

| קובץ | מה יש בו |
|---|---|
| `scenes.js` | התסריט: לכל שקופית הטקסט שעל המסך והקריינות. הסימן `\|` בקריינות מחלק אותה לפעימות, וכל פעימה חושפת את החלק הבא בשקופית. |
| `studio.html` | הסטודיו: תצוגה, עריכת קריינות, יצירת קול וייצוא. |
| `build.mjs` | בונה את `dist/explainer.html`: קובץ אחד עם התסריט והתמונות בפנים, שאפשר לשלוח ולפתוח בלחיצה כפולה. כותב גם את `SCRIPT.md`. |
| `SCRIPT.md` | הקריינות כטקסט רגיל (נוצר אוטומטית). |

## שימוש

1. `node tools/explainer/build.mjs` ופותחים את `tools/explainer/dist/explainer.html` ב-Chrome.
2. מדביקים מפתח API של ElevenLabs (בהגדרות החשבון: Developers > API Keys; צריך הרשאת Text to Speech, ול"טעינת קולות" גם Voices).
3. "טעינת קולות", בוחרים קול, ו"דוגמת קול קצרה" כדי לשמוע. הכי טבעי: לשבט את הקול שלכם (Instant Voice Clone) מהקלטה של דקה-שתיים, ואז הסרטון נשמע כאילו הקלטתם בעצמכם.
4. "יצירת כל הקריינות", ואז "הפעלה מכאן" כדי לצפות.
5. "ייצוא סרטון": הסרטון מתנגן ומוקלט בזמן אמת. משאירים את הלשונית גלויה עד הסוף. ב-Chrome יוצא MP4 (H.264); בדפדפן שלא יודע, WebM.

## הערות

- עברית נתמכת רק ב-Eleven v3 וב-Eleven v4. Multilingual v2 ו-Flash לא תומכים בה.
- הקריינות כ-4,400 תווים, בערך אותו מספר קרדיטים. קטע שכבר נוצר נשמר בדפדפן ולא נוצר שוב עד שמשנים טקסט, קול או מודל.
- המפתח נשמר בדפדפן רק אם מסמנים "לזכור". הוא נשלח רק ל-api.elevenlabs.io.
- את `studio.html` עצמו אפשר לפתוח רק דרך שרת מקומי (למשל `npx serve` משורש הריפו). אם פותחים אותו ישירות מהקובץ, הדפדפן חוסם את ההקלטה של השקופיות בגלל התמונות.
